# Қызылорда су жүйесі — прототип сайта

Двуязычный сайт на Next.js, TypeScript и Tailwind CSS. Казахский язык открывается по умолчанию.

## Запуск

```powershell
npm install
npm run dev
```

Откройте локальный адрес, который напечатает команда запуска (в текущей конфигурации `http://localhost:5173`). Проверка сборки: `npm run build`.

## Содержание и интеграции

- Тексты интерфейса и новости находятся в `lib/content.ts`, проверенные сведения для разделов — в `lib/verified.ts`. Демонстрационная новость хранится отдельно в `demoNews` и явно помечена.
- На самом сайте показаны проверенные сведения о предприятии, контактах, типовом договоре и опубликованных тарифах для бюджетных организаций и прочих потребителей. Ссылки на прежние сайты служат только для сверки первоисточников и документов.
- По примеру структуры [Astana Su Arnasy](https://www.astanasu.kz/) на главной добавлены короткие ответы на типовые вопросы с переходами внутри нашего сайта; на странице отключений усилен прямой доступ к аварийной службе. Данные и онлайн-сервисы Астаны не переносились.
- Актуальные отключения, тарифные суммы для населения и водоотведения, банковские реквизиты и часть форм требуют официального наполнения.
- Передача показаний, оплата и отправка обращений не подключены; сайт не отправляет и не сохраняет введённые данные.
- Форма обращения проверяет обязательные поля и формат телефона или e-mail в браузере, показывает ошибки у полей и после успешной проверки явно сообщает, что отправка не подключена. Таблица тарифов содержит отдельную единицу измерения.
- Интерфейс проверен по `$ui-ux-pro-max`: на 320 px шапка перестраивается в две строки, на промежуточной ширине меню сворачивается, основной текст на телефонах увеличен до читаемого размера. Добавлены пропуск к содержимому и доступная сводка ошибок формы.
- Для публичного сайта задайте `NEXT_PUBLIC_SITE_URL` и проверьте юридическое наименование, контакты и политику обработки персональных данных.
