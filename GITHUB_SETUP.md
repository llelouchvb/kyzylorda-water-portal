# Как выложить проект «Кызылорда Су Жүйесі» на GitHub — пошагово

> ⚠️ Внутри этой среды (Freebuff/Vly) git-команды заблокированы — версионированием управляет платформа.
> Поэтому шаги 1–7 выполняются **на вашем компьютере**, после того как вы скачаете код проекта.

---

## Шаг 0. Скачать код проекта на свой компьютер

Варианты:
- **Скачать ZIP** в интерфейсе Freebuff (кнопка экспорта/скачивания проекта) и распаковать;
- либо скопировать файлы проекта в локальную папку любым удобным способом.

Дальше все команды выполняются в терминале **из папки проекта**.

---

## Шаг 1. Проверить, что git установлен

```bash
git --version
```

Если команды нет — установите: https://git-scm.com/downloads

При первом использовании задайте имя и почту (один раз на компьютер):

```bash
git config --global user.name "Ваше Имя"
git config --global user.email "you@example.com"
```

Почта должна совпадать с почтой вашего аккаунта GitHub, чтобы коммиты связались с профилем.

---

## Шаг 2. Создать пустой репозиторий на GitHub

1. Откройте https://github.com/new
2. Repository name: например `kyzylorda-su-zhuiesi`
3. Выберите **Private** (рекомендую: в коде есть номера телефонов и внутренние данные) или Public — на ваш выбор.
4. **Важно:** НЕ добавляйте README, .gitignore и лицензию при создании — они уже есть в проекте, иначе будет конфликт.
5. Нажмите **Create repository**.

GitHub покажет URL вида:
- SSH: `git@github.com:ВАШ_ЛОГИН/kyzylorda-su-zhuiesi.git`
- HTTPS: `https://github.com/ВАШ_ЛОГИН/kyzylorda-su-zhuiesi.git`

Скопируйте его — понадобится в шаге 4.

---

## Шаг 3. Инициализировать git в папке проекта

```bash
git init -b main
git add .
git status
```

`git status` покажет, что именно попадёт в коммит. Убедитесь, что в списке **нет**:
- `node_modules/`
- `.env` / `.env.local`
- `dist/`

(их отсекает созданный `.gitignore`).

Папка `src/convex/_generated/` **должна** попасть в коммит — это нормально, Convex рекомендует коммитить сгенерированные файлы.

---

## Шаг 4. Первый коммит и привязка к GitHub

```bash
git commit -m "Initial commit: сайт ГКП «Кызылорда Су Жүйесі»"
git remote add origin git@github.com:ВАШ_ЛОГИН/kyzylorda-su-zhuiesi.git
git push -u origin main
```

> Если используете HTTPS вместо SSH, при `git push` GitHub попросит логин и **Personal Access Token** (не пароль). Создать токен: https://github.com/settings/tokens
> Если используете SSH — ключ должен быть добавлен в аккаунт: https://github.com/settings/keys

---

## Шаг 5. Проверить результат

Откройте `https://github.com/ВАШ_ЛОГИН/kyzylorda-su-zhuiesi` — код должен отображаться.

Проверьте, что:
- [ ] папка `node_modules` не загружена;
- [ ] нет файлов `.env`;
- [ ] README.md отображается на главной странице репозитория.

## Шаг 7. Дальнейшая работа с репозиторием (шпаргалка)

```bash
# посмотреть, что изменилось
git status
git diff

# зафиксировать изменения
git add .
git commit -m "Описание изменения"

# отправить на GitHub
git push
```

## Частые проблемы

| Проблема | Решение |
|---|---|
| `git push` отклоняет (`rejected`) | Сначала `git pull --rebase origin main`, затем снова `git push` |
| SSH-ошибка `Permission denied (publickey)` | Добавьте SSH-ключ в аккаунт GitHub (шаг 4) или используйте HTTPS |
| Случайно закоммитили `.env` | Удалите файл из индекса: `git rm --cached .env` и сделайте коммит; **обязательно смените утечка-нутые ключи** |
| Коммит попал не в тот репозиторий | Проверьте `git remote -v`, при ошибке: `git remote set-url origin НОВЫЙ_URL` |

## Дополнительно: подключить Continuous Deploy (по желанию)

Можно привязать репозиторий к Vercel / Netlify / Cloudflare Pages:
1. В настройках хостинга нажмите **Import Git Repository** и выберите репозиторий.
2. Build command: `bun run build` (или `npm run build`), Output directory: `dist`.
3. Добавьте переменную окружения `VITE_CONVEX_URL` (значение из текущего окружения проекта).
4. Для Convex-продакшена отдельно выполните `bun convex deploy` — либо настройте деплой backend'а через CI.
